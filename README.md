# Bitescout - Second Prototype Version

This project was built with [Lovable](https://lovable.dev) as a prototype for a web service idea that I am planning on ultimately building from scratch myself. I plan to use this and the first version as visual and web behavioral references.

The first prototype was built with v0 in accordance with the Vercel mission in Handshake's AI Skills Studio titled "Create Your First Website and Share It on GitHub." I mainly used it as an introductory opportunity to learn how to build using Generative AI.
